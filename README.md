# 🧙‍♂️ Harry Potter Random Spell Generator

Această aplicație web este un "Grimoriu Digital" care permite utilizatorilor să descopere vrăji aleatorii din universul Harry Potter.

## 🌟 Funcționalități
- **Generare Aleatorie:** La fiecare apăsare de buton, o vrajă nouă este extrasă din baza de date.
- **Interfață Tematică:** Design inspirat din lumea vrăjitorilor (Hogwarts), cu efecte vizuale magice.
- **Detalii Vrăji:** Afișează numele vraji, incantația (cuvintele magice) și tipul acesteia (ex: Hex, Charm, Curse).

## 🛠️ Tehnologii Folosite
- **HTML:** Structura semantică a paginii.
- **CSS:** Design responsive, animații și temă Dark Mode.
- **JavaScript:** - `async/await` pentru preluarea datelor.
  - Manipulare DOM pentru afișarea vrăjilor.
  - Gestionarea erorilor (`try/catch`).
- **API:** [Wizard World API](https://wizard-world-api.herokuapp.com/Spells) (API-ul nr. 13 din temă).

## 🚀 Cum se utilizează?
1. Deschide fișierul `index.html` în orice browser modern.
2. Apasă pe butonul **"CAST SPELL ✨"**.
3. O vrajă va apărea pe "pergament".
4. Verifică consola browserului (F12) pentru detalii tehnice despre proces (monitoring).
